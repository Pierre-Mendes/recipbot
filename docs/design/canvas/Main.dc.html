RecipBot Design System v2.0

Feira.
A cozinha de casa, organizada.

A nova identidade do RecipBot troca o laranja genérico e o cinza-azulado por cores de ingrediente: verde manjericão para agir, páprica para destacar, açafrão para avisar, e neutros de farinha para o papel.

Vue 3 + Tailwind 4 Tokens em CSS variables Claro + Escuro WCAG AA

Princípios

01
A receita é a protagonista
Interface calma, sem gradientes nem efeitos de vidro. Título, ingredientes e passos sempre no primeiro plano.
02
Legível com a mão suja
Corpo de 16px no mínimo, alvos de toque de 44px, contraste AA em claro e escuro.
03
Uma cor, um papel
Verde age, páprica destaca, açafrão avisa, vermelho destrói. Nunca decorativo.
04
Tokens antes de classes
Componentes usam só tokens semânticos (bg-primary, text-muted-foreground). Hex solto no código é bug.
